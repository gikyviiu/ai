# ML и AI-консультант

###  Лабораторные работы

#### **Лабораторная работа №1: Задача регрессии**
Применение различных типов регрессии для предсказания уровня инсулина:
- Линейная регрессия
- LASSO регрессия
- Ridge регрессия
- ElasticNet регрессия
- Полиномиальная регрессия (степени 2, 5, 10)

**Метрики:** r2_score, MAE, MSE

---

#### **Лабораторная работа №2: Классификация SVM**
Использование метода опорных векторов (SVM) с различными ядрами:
- Линейное ядро
- Полиномиальное ядро
- Гауссово ядро (RBF)
- Сигмоидное ядро


---

#### **Лабораторная работа №3: Снижение размерности**
Применение методов снижения размерности до двумерного представления (n_components=2):
- PCA (Principal Component Analysis)
- LDA (Linear Discriminant Analysis)
- TruncatedSVD
- Kernel PCA с различными ядрами:
  - linear
  - poly
  - rbf
  - sigmoid
  - cosine
  - precomputed


### **AI-Консультант технической поддержки**

Веб-приложение на Flask с интеграцией YandexGPT для консультаций по тарифам домашнего интернета.

#### **Функциональность:**
- Чат-интерфейс для общения с AI-консультантом
- История сообщений сохраняется в базе данных SQLite

#### **Технологии:**
- **Backend:** Flask
- **База данных:** SQLite + SQLAlchemy
- **LLM:** YandexGPT (через OpenAI-compatible API)
- **Frontend:** HTML/CSS/JavaScript
